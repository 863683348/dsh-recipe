# dsh-recipe — 插件界的 dotfiles（配方聚合）

把 dsh 插件打包成**场景配方**：说一句"我要一套 XX 环境"，拿到有序插件清单和安装命令——从"装单个"到"装环境"。

## 内置配方（10 个）

浏览器开发环境、通知全家桶、学术写作套装、移动远程控制、安全加固套装、记忆持久化套装、娱乐休闲、模型路由优化、工作流自动化、插件市场管理。

## 用法

`recipe` 工具：`list` 浏览、`search` 按需求匹配、`apply` 展开（有序插件 + 安装命令）、`compose` 合并多配方去重。

## 设计

`lib/recipe.js` 纯逻辑零依赖；配方 JSON 即"插件清单+顺序+配置"；`compose` 做并集去重，可对接 DAG 编排。无网络、无写入、无 secrets。
